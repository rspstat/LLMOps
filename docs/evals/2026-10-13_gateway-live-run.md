# 게이트웨이 실가동 확인 (Qwen + Jev, 2026-10-13)

> 평가 도구가 아니라 **게이트웨이 서버(HTTP)** 를 실제 모델로 켜서 요청을 보내 본 첫 확인입니다. 이전까지 서버는 mock과 자동 테스트로만 검증했습니다.

## 구성

| 항목 | 값 |
|---|---|
| 서버 | `uvicorn gateway.app:create_app --factory`, 포트 8800(정상 시나리오), 8801(장애 시나리오) |
| 라우팅 | `ROUTER_MODE=hybrid`, `ROUTER_PROMOTE_THRESHOLD=0.995` (이 실행에서만 환경변수로 덮어씀. 기본값 0.7은 Jev `p(easy)`가 최소 0.94라 전부 소형으로 간다) |
| 소형 / 상용 / 판정 | `qwen3.7-flash` / `qwen3.8-max` / Jev(`jev-1.13.0`), 정책 `v1` |
| 인증 | 이 실행용 임시 키(저장·출력하지 않음) |
| 저장소 | 별도 SQLite 파일(`data/live-demo.sqlite3`, `.gitignore` 대상) |
| 총 비용 | 약 $0.0004 (모델 호출 5회, 판정 호출 5회) |

- 다단계 속력 문제는 평가에서 소형 모델이 틀렸던 문항(`en-math-05`, 60 대 정답 75)과 같은 문제입니다. 임계값 0.995에서 판정기가 상용으로 올려 보내 정답을 얻었습니다. 평가에서 본 순위 신호가 서버에서도 같은 방향으로 작동한 사례 1건입니다(통계적 증거는 아님).
- 모든 정상 요청에서 trace가 `guard → judge → router → provider` 순서로 저장됐고, 판정 확률·모델·토큰·비용·지연이 기록됐습니다. `router` 단계의 지연에는 판정기 호출 시간이 포함됩니다.
- 요청당 비용은 판정기가 약 $0.00002로 소형 모델($0.000001)의 약 20배입니다. 평가에서 본 판정 비용 부담이 서버에서도 확인됐습니다.

### 모델 장애 시나리오

소형 모델의 키를 일부러 잘못된 값으로 덮어쓰고 쉬운 질문을 보냈습니다.

- 소형 호출이 `HTTP 401`로 실패했고(`provider error`, 과금 없음), 이어서 `fallback-mock`이 응답했습니다(`fallback: true`). 요청은 **200으로 성공**했습니다.
- 응답 내용은 `[fallback-mock] What is the capital of France? Answer with one word.` 로, 질문을 그대로 따라 말한 의미 없는 문장입니다.

## 확인된 요구사항

[product.md](../product.md)의 FR-1~FR-8이 실제 모델로 동작하는 것을 확인했습니다(FR-1은 일부 지원 범위 안에서).

## 발견한 문제 (아직 고치지 않음)

1. **fallback 응답이 의미 없는 echo인데 HTTP 200으로 나간다.** 클라이언트는 성공한 답으로 읽고, 장애 사실은 응답의 `model` 필드와 trace에서만 알 수 있다. 장애가 조용히 묻힌다. 후보: (a) 응답 헤더로 fallback 사용을 알린다(예: `X-LLMOps-Fallback`). (b) mock 대신 **다른 경로의 실제 모델**(소형이 죽으면 상용)로 먼저 대체한다. (c) 모든 실제 모델이 실패했을 때만 503을 돌려준다. 설계 결정이 필요하다.
2. **401과 422의 오류 본문이 OpenAI 형식이 아니다.** 입력 가드와 스트리밍 거절은 `{"error": {"message", "type", "code"}}` 이지만, 인증 실패와 요청 검증 실패는 FastAPI 기본 형식 `{"detail": ...}` 이다. OpenAI SDK를 쓰는 클라이언트는 오류 본문을 일관되게 읽지 못한다.
3. **기본 임계값(0.7)이 Jev와 맞지 않는다.** 서버를 `hybrid`로 켜도 기본값으로는 판정이 의미가 없다. 설정으로 0.99대로 올려야 한다. 정책 v2 이후 기본값을 정해야 한다.
4. 응답에 선택된 경로와 판정 확률이 드러나지 않는다. trace는 DB에만 있고 조회 API는 의도적으로 없다. 시연 화면을 만들려면 응답 헤더나 별도의 안전한 조회 수단이 필요하다.
