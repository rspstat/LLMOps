# AI 대화 기록

AI 도구와 나눈 대화를 **날짜별 파일**로 보관하는 폴더입니다. 프로젝트를 시작한 시점부터 빠짐없이 쌓는 것이 중요합니다.

## 파일 이름

`YYYY-MM-DD_주제.md` (예: `2026-10-12_프로젝트-기획.md`)

## 각 파일에 적을 것

```markdown
# 2026-10-12 · 프로젝트 기획

- 사용 도구: (예: Claude, Claude Code)
- 목적: (이 대화로 하려던 것)

## 핵심 프롬프트
(실제로 입력한 프롬프트. 수정해서 다시 요청한 경우 그 과정도 함께)

## AI 응답 요약 / 채택한 내용
(그대로 쓴 것, 고쳐서 쓴 것, 버린 것과 그 이유)

## 결과물
(만들어진 커밋/파일 링크)
```

## 도구별 보관 방법

- **Claude Code**: 세션이 끝나기 전에 `/export docs/ai-log/YYYY-MM-DD_주제.md` 로 대화를 텍스트로 저장합니다. (Claude Code는 대화를 `~/.claude/projects/` 아래에도 JSONL로 저장하지만, 제출용으로는 export한 파일을 쓰는 것이 편합니다.)
- **Claude 웹 채팅 등 다른 도구**: 대화 원문을 복사하거나 내보내기 기능으로 저장해 같은 폴더에 둡니다.

## 원칙

- 대화 원문은 가능하면 **내보내기(export) 파일 그대로** 보관하고, 위 형식의 요약을 함께 둡니다.
- 프롬프트를 고친 이유, AI의 오류를 발견해 바로잡은 과정(트러블슈팅)을 구체적으로 남깁니다.
- API 키, 개인정보가 대화에 섞였다면 **커밋 전에 지웁니다**. 이 레포는 Public입니다.
