## AI 응답 요약 / 채택한 내용

- **Jev 조사**: 웹 검색으로 확인. TypeSafe AI가 2026-09-15 공개한 판정 전용("System One") 모델이며 글을 생성하지 않고 정해진 선택지 중 답과 확률·신뢰도를 반환. 속도·비용 수치(70~500ms, 입력 100만 토큰당 $0.042, 출력 무료)는 **회사 발표 기준**이라 직접 벤치마크로 검증하기로 함.
- **아이디어 10개 중 채택**: b(RouteWise, 라우터 게이트웨이) + a(EvalForge, 평가) + f(GuardGate, 가드레일) + j(Hybrid-1/2, 하이브리드 에이전트 프레임워크)를 하나의 LLMOps 플랫폼으로 통합. 나머지(c, d, e, g, h, i)는 채택하지 않음.
- **통합 구조**: j를 b의 일반화로 보고 라우팅 엔진으로 합침 → 가드 · 라우팅 엔진 · 평가의 세 모듈, 모든 단계 trace 기록, 평가 결과로 정책을 개선하는 폐쇄 루프.
- **설계 원칙**: Jev는 선택지가 정해진 판정에만 사용하고, 계산은 코드·생성은 다른 모델이 담당. provider 추상화로 Jev를 교체 가능하게 하여 Jev 자체도 평가 대상(Jev vs 파인튜닝 분류기 vs LLM judge)으로 둠.
- **범위 조절**: GPU 제약으로 파인튜닝은 1B 이하, 일정이 밀리면 judge 증류·가드 파인튜닝부터 제외.
