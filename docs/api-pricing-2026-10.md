# LLM API 비용 비교 (2026년 10월 기준)

> 작성일 2026-10-13. 이 프로젝트에서 **소형(small) 모델 · 상용(frontier) 모델 · 판정기(judge)** 를 고르기 위한 비교표이다. 추천도는 "이 프로젝트에서의 적합도"이지 모델의 일반 품질 순위가 아니다. 품질은 직접 측정하는 것이 이 평가 도구의 목적이다.

## 읽는 법

- **단가**: USD / 100만 토큰, 표준 요금(배치·우선순위·캐시 할인 제외), 짧은 컨텍스트 기준(OpenAI ≤272K, Gemini ≤200K).
- **1천 건당 비용**: 요청 1건이 입력 500토큰 · 출력 300토큰이라고 가정한 값 = 0.5 × 입력단가 + 0.3 × 출력단가. 실제 요청 길이에 따라 비례해서 달라진다.
- **평가 1회 상한**: 이 레포의 평가 데이터셋 80문항을 모델 하나가 한 번 처리할 때의 비용 상한(출력은 최대 64토큰으로 가정, 입력 토큰은 글자수÷4 추정이라 한국어는 더 클 수 있음).
- **OpenAI 호환**: 현재 어댑터(`providers/openai_compat.py`)로 바로 쓸 수 있는지. ✗는 전용 어댑터를 새로 만들어야 한다는 뜻이다.
- **추론 모델**: 숨은 추론에 토큰을 쓰는 모델은 평가의 `max_tokens=64` 안에서 답이 비어 **오답으로 채점**된다(수집 중 빈 응답 경고가 뜬다). "✓ 비추론"은 알려진 사실, "미확인"은 공식 가격 페이지가 알려 주지 않아 확인하지 못했다는 뜻이다.
- **확인 수준**: OpenAI·Google·DeepSeek·Alibaba(Qwen)는 공식 페이지에서 2026-10-13에 직접 읽은 값, Anthropic은 Claude API 레퍼런스(2026-10-06 캐시), Jev는 회사 발표값(제3자 문서 인용)이다.

## 4. 추천 조합

| 조합 | 구성 | 평가 1회 상한 | 키 | 특징 |
|---|---|---|---|---|
| **A. 권장** | gpt-4.1-nano + gpt-4.1 + Jev | ≈ $0.047 | OpenAI 1개 + Jev 1개 | 모두 현재 어댑터로 즉시 동작. 두 모델 모두 비추론이라 빈 답 문제 없음 |
| B. 소형 무료 | gemini-2.5-flash-lite(무료 구간) + gpt-4.1 + Jev | ≈ $0.045 (소형이 무료 구간일 때. 유료면 A와 같은 ≈ $0.047) | Google + OpenAI + Jev | 소형이 $0. 호환 계층 beta와 thinking 동작 확인 필요 |
| C. 저가 대안 | deepseek-flash + deepseek-v4-pro + Jev | ≈ $0.015 | DeepSeek 1개 + Jev | 가장 저렴. 추론 여부 미확인, 피크 시간 2배 |
| **D. Qwen 한 곳** | qwen3.7-flash + qwen3.8-max (둘 다 `enable_thinking:false`) + Jev | ≈ $0.035 | Alibaba 1개 + Jev | 한 키로 소형·상용 호출. 소형이 거의 공짜(무료 100만 토큰 안). 둘 다 추론 기본이 켜져 있어 추가 필드가 필수 |
| D'. Qwen 무설정 대안 | qwen-flash + qwen-max + Jev | ≈ $0.038 | Alibaba 1개 + Jev | 추가 필드 없이 동작(qwen-flash는 추론 기본 꺼짐, qwen-max는 비추론 전용). 둘 다 구세대 |

조합 A는 OpenAI 키 하나로 소형과 상용을 모두 호출할 수 있다(`SLM_BASE_URL`과 `FRONTIER_BASE_URL`이 같은 `https://api.openai.com/v1`).

> **조합 A의 "권장"은 설정 위험이 가장 낮다는 뜻이지 성능이 가장 좋다는 뜻이 아니다.** `gpt-4.1` 계열은 구세대이다. 같은 시대 모델끼리 벤더를 비교하려면 GPT-6 계열(`gpt-6-luna` + `gpt-6.1-sol`)이 맞지만 추론 기본값이 미확인이라 설정 확인이 필요하다. 2026-10-13 첫 실측(Qwen 3.7-flash / 3.8-max)이 소형 91.2%, 상용 97.5%로 이미 좋았기 때문에, 이 문서 시점의 실제 선택은 조합 D(Qwen)로 정해졌다. 조합 A는 "다른 벤더와 비교하고 싶을 때의 안전한 시작점"이라는 의미로만 읽어야 한다.

**산술 예시 (측정값 아님)**: 조합 A로 요청 1천 건을 처리할 때, 전부 상용이면 $3.400이고, 70%를 소형·30%를 상용으로 완벽하게 나눈다고 가정하면 판정 비용을 포함해 $1.152로 약 66% 절감된다. 실제 절감률은 판정 정확도와 요청 분포에 달려 있고, 그것을 재는 것이 3단계 평가의 목적이다.

## 5. 주의 · 한계

- **가격은 수시로 바뀐다.** 결제 전에 각 제공사 가격표를 확인해야 한다. 이 문서의 단가를 `.env`의 `*_PRICE_*`에 그대로 넣어도 되지만 확인 책임은 사용자에게 있다.
- **기간 한정 요금**: 공식 OpenAI 페이지는 `gpt-5.6-sol`의 프로모션 가격이 최소 2026-11-21까지라고 적고 있다. Gemini 3.6/3.8 Flash는 2026년 말까지 $0.75 / $3.75이고 2027-01-01부터 $1.50 / $7.50이다.
- **제외한 것**: 장문 컨텍스트 할증, 캐시·배치 할인, 세금·환율, 무료 구간의 속도 제한(공식 가격 페이지에 한도가 없음).
- **계정 접근**: 계정 등급이나 지역에 따라 일부 모델을 쓰지 못할 수 있다. `scripts/smoke_live.py`로 1회 호출해 확인해야 한다.
- **추론 여부 "미확인"**: OpenAI 공식 가격 페이지는 모델의 추론 여부를 표시하지 않는다. 추측으로 채우지 않았고, 수집 중 "빈 응답" 경고가 뜨면 추론 모델이라는 신호이다.
- **Qwen(Alibaba Cloud Model Studio)**: 가격은 국제(싱가포르) 정가이며 같은 페이지가 무료 100만 토큰(90일)을 안내한다. OpenAI 호환 모드가 있고 키는 `Authorization: Bearer`로 보내지만, **API 키가 만들어진 리전에 묶이고** 엔드포인트가 `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` 형태(워크스페이스 ID 필요)이다. **추론 기본값(공식 deep-thinking 문서)**: `qwen3.8-max`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.7-flash`, `qwen3.6-flash`는 추론이 **기본 켜짐**이고 `qwen-flash`는 기본 꺼짐이다. `qwen-max`는 이 문서에 없지만 가격 페이지가 "비추론 전용"으로 표기한다. 끄는 방법은 요청 본문에 `enable_thinking: false`를 넣는 것(OpenAI SDK에서는 `extra_body`)이며, 추론 토큰은 출력 토큰으로 과금되고 `completion_tokens`에 포함된다. 그래서 끄지 않으면 평가의 `max_tokens=64` 안에서 빈 답이 난다. 이 레포는 `SLM_EXTRA_BODY` / `FRONTIER_EXTRA_BODY`(JSON)로 이 필드를 보낸다. `temperature=0`은 허용 범위([0, 2))이지만 문서가 권장하지 않는다고 적고 있다.

**2026-10-13 실측 확인**: `qwen3.7-flash`와 `qwen3.8-max` 모두 `enable_thinking: false`를 받아들였고 완료 토큰이 1(추론 토큰 없음)이었으며, 80문항에서 `temperature=0` 호출도 성공했다. 첫 호출은 base URL에 `/compatible-mode/v1` 경로를 빠뜨려 404였고, 두 모델 키가 한 글자 달라 401이 났다(둘 다 설정 오류). 결과: [docs/evals/2026-10-13_qwen-first-run.md](evals/2026-10-13_qwen-first-run.md).
- **Qwen 품질**: 한국어 소형 모델 직접 비교 자료는 찾지 못했다. Qwen 모델 카드는 201개 언어 지원을 주장하고(제작사 주장), 한국어 퍼즐 벤치마크(NOLLI)에서는 Qwen 계열 안에서 모델이 클수록 정확도가 올랐다는 결과만 확인했다. "Qwen이 더 낫다/못하다"를 이 문서로 판단할 수 없고, 이 레포의 평가로 직접 재야 한다.
- **Claude(Anthropic)**: 가격은 좋지만 OpenAI 호환 엔드포인트가 아니라서 전용 어댑터가 필요하다. 로드맵상 이후 단계 후보이다.
- **확인하지 못한 제공사**: Groq는 공식 가격 페이지에서 단가를 읽지 못했고, Mistral·Together 등은 조사하지 않았다.
- **무료 구간 데이터 정책**: 무료 구간은 입력이 제공사의 서비스 개선에 쓰일 수 있는 약관이 흔하다(이 문서는 약관을 확인하지 않았다). 이 레포의 평가 데이터셋은 공개 가능한 합성 문항이라 문제가 없지만, 개인정보가 든 데이터는 넣지 않는다.
